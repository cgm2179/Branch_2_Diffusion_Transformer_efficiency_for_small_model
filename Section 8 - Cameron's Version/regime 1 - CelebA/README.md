# §8 regime 1 · CelebA (from-scratch ViT, 40-attribute classification)

Five rules train the same ~1.01M ViT to predict all 40 CelebA face attributes (multi-label), matched on equal wall-clock; loss = BCE, metric = mean per-attribute accuracy. 64x64 RGB, patch 8 (64 tokens). Three-factor cos sweep clean/normal/noisy = cos 0.5/0.09/0.01. Checkpoints to Drive (`Section8_r1_celeba/`), live plot, `results/<method>.json`. `07` adds a 100M backprop ceiling. Compare in `CelebA - 06_compare_results.ipynb`. Data: set `CELEBA_ROOT` to the aligned-JPG folder (contains the images + list_attr_celeba.csv; first run decodes a subset + caches a .pt; on Colab unzip to a local path). NOTE: from-scratch full-model local training is barrier-limited (K=1, M*≈P/3) — the point is method ordering + the cos sweep, and the majority-class attribute baseline is high.
